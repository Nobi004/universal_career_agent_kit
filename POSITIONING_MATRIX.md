# Positioning Matrix

## Core narrative

MD. Mahmudun Nobi is an applied AI engineer focused on building useful AI-enabled software: agentic workflows, LLM applications, retrieval systems, document intelligence, and backend/product integration. He also brings experience coordinating engineering work and an academic/research interest in machine learning and computer vision.

Do not make this narrative sound like a list of buzzwords. Every application should select two or three proof points relevant to the vacancy.

## Role-specific positioning

| Role family | Lead with | Supporting proof | Avoid |
|---|---|---|---|
| Applied AI Engineer | End-to-end AI feature delivery | LangGraph business-data agent; ACORD pipeline; Voice Mind | Claiming deep research specialization when role is product engineering |
| Agentic AI Engineer | Tool orchestration, workflow state, reliable task execution | LangGraph; CareerOS agent workflows; AURA only where implementation is demonstrable | Calling every LLM chain an autonomous agent |
| GenAI / LLM Engineer | RAG, embeddings, retrieval, evaluation, API integration | Voice Mind, FAISS, LLM application work | Listing every model provider without hands-on evidence |
| Full-Stack AI Engineer | AI feature + backend + product interface | CareerOS and verified deployed projects | Presenting broad stack familiarity as expert-level depth |
| AI Backend Engineer | Python services, APIs, data flow, validation, reliability | Document pipeline, business-data agent | Overstating infrastructure ownership |
| ML Engineer | Data preparation, model training/fine-tuning, evaluation, deployment | LayoutLMv3 / computer-vision research where verified | Claiming production ML operations without monitoring evidence |
| Computer Vision Engineer | Image/document pipelines, model architecture, evaluation | IEEE paper, WBFVD work, ACORD visual document processing | Mixing academic experiments with production deployment |
| AI Research Engineer | Reproducible experiments, papers, model evaluation | Verified IEEE paper and academic work | Claiming research leadership or publication impact without evidence |
| Technical Lead | Technical direction, mentoring, reviews, delivery coordination | Q-Bit Coders leadership after team scope is verified | Applying to people-management-heavy roles without confirming direct reports |

## Headline variants

1. **Default:** Applied AI Engineer | Agentic AI & LLM Systems | Full-Stack AI Product Development
2. **LLM-focused:** AI Engineer | LLM Applications, RAG & Agentic Workflows
3. **Product-focused:** Full-Stack AI Engineer | Python, LLM Systems & Production AI Products
4. **ML-focused:** Machine Learning Engineer | Applied AI, Document Intelligence & Computer Vision
5. **Leadership-focused:** AI Engineer & Technical Team Lead | Agentic AI, LLM Systems & Product Delivery

Use only one headline per platform. Match the headline to the platform audience and target vacancies.

## Positioning rules

- Lead with what the candidate builds and the problems solved.
- Use “production” only when the system was deployed for real users or business operations.
- Separate professional employment, independent projects, academic research, and prototypes.
- Do not use “Senior”, “Architect”, “Principal”, “Staff”, or “Founder” as default labels.
- Avoid “expert in everything” skill lists. Use depth tiers: production, substantial project, academic, familiar.
- A role is not a fit merely because it mentions AI. Evaluate actual responsibilities and required depth.
